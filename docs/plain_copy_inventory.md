# Enprive End-User Copy Audit & Plain-Language Inventory

Target audience: **Teachers, educators, parents, and children (approx. 10–12 year old reading level for core flows)** per the Education Wedge Strategy and Master Product Specification v3.

## Classification Legend
- **keep**: Already plain, clear, and accurate for teachers, parents, and students, or legally/calibration-required copy (`"No concern identified in the reviewed evidence. This is not a safety certification."`).
- **simplify**: Rewritten in plain language to remove developer/internal vocabulary (`snapshot`, `digest`, `FNV-1a`, `SHA-256`, `manifest`, `PackageManager`, `deterministic`, `clause`, `payload`, `PII`, `masked`, `scrubbed`, `App Check`, `Puck`, `OS Granted`, `sourceMatched`, `deviceObserved`, `AD_ID`, `OTP`, `HTTP` jargon) while keeping evidence and consent honesty exact.
- **move to advanced details**: Technical verification data that matters for audit/trust (document fingerprint/hash, canonical/redirect URL, capture time, file MIME/size/status, check ID / thought signature) moved behind a collapsed **"Advanced details"** or **"How Enprive checked this"** disclosure with a plain one-line explanation.
- **remove**: Developer-only surface clutter removed from primary card faces (e.g., raw `App Check` progress pill, raw enum `.name` printout, live-streaming `thoughtSignature` token pill, raw package name appended to `sourceLabel` heading).
